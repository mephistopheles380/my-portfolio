# Pranav Kumar - Personal Portfolio

A modern, interactive, production-quality portfolio website for **Pranav Kumar**, showcasing expertise in **Data Analytics**, **Python Development**, and **Cybersecurity**.

## 🌟 Highlights & Features

- **3D Interactive Experience**: Bespoke interactive Three.js 3D data sphere / particle network reflecting cursor movements with performance optimizations and accessibility support (`prefers-reduced-motion`).
- **Verified Resume Integration**: Direct download buttons in the Navbar, Hero, and Contact sections serving the authentic `Pranav_S_Kumar_Resume.pdf`.
- **Tripartite Pillars ("What I Work With")**: Interactive cards illustrating Data, Development, and Security.
- **Academic Credentials & About**: Verified academic achievements (B.Tech in CS & Cyber Security with CGPA 6.72, Plus Two 90.75%, SSLC 98.89%).
- **Interactive Competencies**: Grouped skill categories with zero fake percentage bars.
- **Featured Project & Simulator**: Deep showcase of the *Masked Face Recognition and Reconstruction System* (Python, OpenCV) with an interactive face mesh occlusion simulator and repository link.
- **Interactive Automation Pipeline**: Step-by-step visual continuum: `DATA` → `PYTHON` → `ANALYSIS` → `INSIGHT` → `AUTOMATION`.
- **Evolutionary Journey**: Vertical milestone timeline capturing the progression into Data Science & AI.
- **Actionable Contact Suite**:
  - Direct WhatsApp CTA with pre-filled message (`https://wa.me/917306893083?text=...`)
  - Email (`mailto:pranavskumarvarakukalayil@gmail.com`)

  - One-click copy buttons for email and phone numbers with visual feedback.

## 🚀 Getting Started

### Prerequisites

- Node.js (v20.19+ or v22+) & npm

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

The compiled assets will be in the `dist/` directory, ready to be hosted on Vercel, Netlify, GitHub Pages, or any static hosting provider.

### Preview Production Build

```bash
npm run preview
```

## ⚙️ Customization & Updating Content

All data is centralized in a single file for convenience:
👉 `src/data/portfolioData.ts`

- **Personal details & Social Links**: Modify `PERSONAL_INFO` (e.g. LinkedIn, GitHub, email, phone).
- **Projects**: Edit `PROJECTS_DATA` to add new projects or replace the "More projects coming soon" placeholders.
- **Skills**: Add or remove skills in `SKILL_CATEGORIES`.
- **Resume**: Replace `public/Pranav_S_Kumar_Resume.pdf` whenever you update your resume.
